# QuestHunt Flutter App

Dieser Ordner enthält eine kleine Beispiel-App in Flutter, die den in HTML/CSS/JS gezeigten Prototypen nachbildet.

## Installation

1. [Flutter](https://docs.flutter.dev/get-started/install) installieren.
2. In diesem Verzeichnis `flutter pub get` ausführen.
3. Anschließend mit `flutter run` auf einem Emulator oder Gerät starten.

Die App simuliert NFC-Scans über den "NFC Scannen"-Button. Jede Mission wird freigeschaltet, sobald die vorherige abgeschlossen ist. Sind alle Missionen erledigt, erscheint ein Glückwunsch-Dialog und das Spiel kann zurückgesetzt werden.
